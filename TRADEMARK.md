The Gerfaut source code is licensed under the AGPL-3.0. That license covers code only. The project's identity, meaning the name "Gerfaut", the gyrfalcon logo, the wordmark, and the visual identity as a whole, is not covered by the code license and remains the exclusive property of Loïc Morel. All rights reserved.

This split is deliberate: anyone may use, study, modify, and redistribute the code under the AGPL, but the identity is what tells users they are running the official software, and it does not follow the code.

## Allowed without permission

You may, without asking:

- Use the Gerfaut name and unmodified logo to refer to the project: articles, tutorials, reviews, talks, presentations, videos, screenshots, academic work.
- State truthfully that your software is based on, compatible with, or forked from Gerfaut.
- Link to the official repositories and website.

This is nominative fair use. Attribution is appreciated but not required.

## Not allowed without written permission

- Using the Gerfaut name or logo, or confusingly similar ones, to name, brand, or market a fork, derivative, product, or service.
- Modifying the logo, or combining it into your own branding.
- Using the name or logo in domain names, app-store listings, or social-media handles.
- Suggesting official status, endorsement, or affiliation where none exists.

Forks are welcome, and they are exactly what the AGPL is for: under a different name and a different logo.
